# Reel symbol assets

Place the exact bitmap images you want to use in this folder. The game is wired to use these filenames:

- `scarab.png`
- `ankh.png`
- `falcon.png`
- `winged-sun.png`
- `queen.png`
- `cleopatra-top.png`
- `cleopatra-middle.png`
- `cleopatra-bottom.png`
- `a.png`
- `k.png`
- `q.png`
- `j.png`
- `ten.png`

Use PNG, JPG, JPEG, or WebP if you prefer, but update the matching `image` paths in `src/main.js` if the extension is not `.png`.

For Cleopatra, provide either three cropped files matching the top, middle, and bottom visible reel cells, or provide one full-height portrait and ask Copilot to split/wire it.
